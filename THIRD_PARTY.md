## CodeFronts, "Particle Burst" CSS tabs

- **Source:** https://codefronts.com/navigation/css-tabs/particle-burst/
- **Author:** CodeFronts (https://codefronts.com)
- **Licence:** MIT

Used as the tab bar under the header: a sliding underline and an eight-spark
burst. The original vanilla HTML/CSS/JS was adapted into the `.pt-*` rules and
the tab script in `app/templates/base.html`. The underline and the sparks are
themed to CouchElephant's own palette, read from CSS custom properties so they
follow the light and dark themes. The animation technique, per-particle
trajectory through the `--dx` and `--dy` custom properties with the sparks
spawned by script, is unchanged.

These pages are server rendered rather than a single-page app, so the slide is
replayed on load from the tab the reader came from instead of running on click.

## Team catalogue

`app/data/teams.json` is a list of team names, leagues and sports, generated by
`scripts/build_teams.py` from ESPN's public team endpoints. It holds no
schedules, scores, logos or identifiers belonging to anyone else, and the
running application never calls out to build it. Team names are facts about the
world rather than creative work.

## hls.js

`app/static/js/vendor/hls.min.js` is hls.js 1.5.17, the full build,
unmodified. It plays the viewing copy of a recording in browsers that do not
play HLS on their own. The full build, because the light one leaves out the
broadcast captions. Copyright (c) 2017 Dailymotion, licensed under the
Apache License 2.0: https://github.com/video-dev/hls.js/blob/master/LICENSE

## Comskip

The container image carries `comskip`, built unmodified from
https://github.com/erikkaashoek/Comskip at commit
a140b6ac8bc8f596729e9052819affc779c3b377 (see the `Dockerfile`). It finds the
ad breaks in a recording so CouchElephant's players can offer a Skip button.
CouchElephant runs it as a separate program and does not link to it.
Copyright (c) Erik Kaashoek and contributors, licensed under the GNU General
Public License, version 2: https://github.com/erikkaashoek/Comskip/blob/master/LICENSE.
The source for the exact build is at the commit above.

## Programs bundled in the installers

The Windows, macOS and Linux installers carry three programs, each run as a
separate process (CouchElephant does not link to them). The exact builds are
pinned by URL and SHA-256 in `packaging/tools.json`. Their licences sit in the
install folder's `bin/` as `LICENSE-ffmpeg.txt` and `LICENSE-comskip.txt`
(copies are kept in `packaging/licenses/`).

- **ffmpeg and ffprobe**, FFmpeg 9.x static builds, GNU General Public
  License, version 3 (the GPL builds, which include x264 and x265).
  Windows and Linux: BtbN's FFmpeg-Builds, release
  `autobuild-2026-11-18-12-39`, https://github.com/BtbN/FFmpeg-Builds .
  macOS: Martin Riedl's build server, version 9.0.2,
  https://ffmpeg.martin-riedl.de . Copyright (c) the FFmpeg developers,
  https://ffmpeg.org/legal.html .
- **comskip**, GNU General Public License, version 2. Linux and macOS
  installers carry it built unmodified from the commit named above by
  `packaging/build_comskip.sh`. The Windows installer carries the upstream
  Windows build 0.82.012 from https://www.kaashoek.com/files/comskip82_012.zip ,
  whose source is the Comskip repository at commit
  9900227ae759e631e29abbbce99df6742651cfc5 (the last commit before that build
  was made, 2022-02-25): https://github.com/erikkaashoek/Comskip/tree/9900227ae759e631e29abbbce99df6742651cfc5 .

**Source offer.** The corresponding source for every program above is public.
FFmpeg: https://ffmpeg.org/releases/ and the build scripts in the two build
projects named above. Comskip: https://github.com/erikkaashoek/Comskip . If
any of that is ever unavailable, write to the project's issue tracker at
https://github.com/beamflash/couchelephant/issues and the matching source will
be provided for three years after the release that shipped the program.
